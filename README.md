# WeIntern – Empowering Student Careers

A modern and responsive internship landing page built using **HTML, CSS, and JavaScript**. This project showcases internship opportunities in AI, Data Science, and Web Development with a clean UI, animations, responsive design, and interactive form validation.

---

## 🚀 Features

* Responsive modern landing page
* Interactive navbar with scroll effect
* Mobile hamburger menu
* Smooth scrolling navigation
* Hero section with animated cards
* Internship tracks section
* Apply form with validation
* Scroll reveal animations
* Clean UI with modern color palette
* Fully beginner-friendly frontend project

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Google Fonts (Poppins)

---

## 📁 Project Structure

```text
.
├── index.html
├── style.css
└── script.js
```

---

## 📄 File Description

### `index.html`

Contains the structure of the website including:

* Navbar
* Hero section
* About section
* Internship tracks
* Call-to-action form

### `style.css`

Handles:

* Layout styling
* Responsive design
* Animations
* Color themes
* Buttons and cards styling

### `script.js`

Implements:

* Navbar scroll effect
* Mobile menu toggle
* Active navigation highlighting
* Form validation
* Scroll reveal animations
* Track card interactions
